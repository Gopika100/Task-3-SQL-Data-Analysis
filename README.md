# Task 3: SQL for Data Analysis

## Objective

Use SQL to extract, manipulate, and analyze structured
e-commerce data using a relational database.

## Tools Used

- SQLite
- Google Colab
- Python
- Pandas

## Dataset

A sample e-commerce database containing:

- Customers
- Products
- Orders
- Order Details

## SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate Functions
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN Equivalent
- Subqueries
- Views
- Indexes

## Analysis Performed

- Product price analysis
- Product category analysis
- Total sales
- Average order value
- Customer spending analysis
- Best-selling products
- Order analysis
- Final revenue analysis

## Project Outcome

This project demonstrates the use of SQL for querying,
joining, aggregating, and analyzing structured e-commerce data.

## Files

- `Ecommerce_SQL_Analysis.sql` - SQL queries used for the analysis
